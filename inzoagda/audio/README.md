# Inzoagda map: band samples

Single-note recordings of real instruments, trimmed and converted to mono mp3 for the background band in `inzoagda.html`.

- Pitched instruments (`bass_*`, `guitar_*`, `piano_*`, `accordion_*`, `violin_*`, `clarinet_*`, `flute_*`): FluidR3 GM soundfont, via https://github.com/gleitz/midi-js-soundfonts. License: Creative Commons Attribution 3.0.
- Hand drums and shakers (`doum`, `tek1`, `tek2`, `ka`, `frameL`, `cajon*`, `tamb*`, `shak*`): Versilian Community Sample Library (VCSL), https://github.com/sgossner/VCSL. License: CC0.
